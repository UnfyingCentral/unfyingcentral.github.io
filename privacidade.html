1. Dados usados

  • Tokens de acesso dados pela plataforma quando o criador autoriza a conta.
  • Informações básicas do perfil da conta conectada (identificador, nome de usuário, nome de exibição e foto), para confirmar a conta certa e mostrá-la na tela de postagem.
  • Dados das publicações do próprio criador: identificador, link e números públicos de desempenho.

A Central não coleta dados de seguidores, de espectadores nem de outras pessoas.

2. Finalidade

Somente publicar os vídeos aprovados pelo criador nas contas dele e mostrar a ele o desempenho desses vídeos.

3. Armazenamento

Os tokens ficam num arquivo de configuração protegido no computador ou servidor do criador, com acesso restrito. Nenhum dado é enviado a terceiros além das próprias plataformas, nas chamadas das APIs oficiais.

4. Compartilhamento

Os dados não são vendidos, alugados nem compartilhados.

5. Retenção

Os tokens são guardados enquanto a conta estiver conectada e apagados ao desconectar.

6. Como revogar

  • TikTok: Configurações e privacidade → Segurança → Apps e serviços → remover "Central do Canal".
  • YouTube / Google: myaccount.google.com/permissions → remover "Central do Canal".

YouTube API Services

A Central do Canal usa os YouTube API Services. Ao conectar um canal, o criador concorda com os Termos de Serviço do YouTube. Os dados do YouTube também seguem a Política de Privacidade do Google. O acesso pode ser revogado a qualquer momento em security.google.com/settings/security/permissions.

Privacy Policy (English)

Data used: access tokens granted by the platform when the owner authorizes an account; basic profile information of the connected account (ID, username, display name and avatar) to confirm the right account and show it on the posting screen; and data about the owner's own posts (ID, link and public performance numbers). No data about followers, viewers or any other person is collected. Data is used only to publish videos approved by the owner and to show their performance. Tokens are stored in a protected configuration file on the owner's computer or server and are sent to no one except the platforms themselves through official API calls. Data is never sold or shared. Tokens are kept while the account is connected and deleted when it is disconnected. Access can be revoked at any time in TikTok (Settings and privacy → Security → Apps and services) or Google (myaccount.google.com/permissions).

YouTube API Services. Central do Canal uses YouTube API Services. By connecting a channel, the user agrees to be bound by the YouTube Terms of Service. YouTube data is also subject to the Google Privacy Policy. Access can be revoked at any time at Google security settings.
